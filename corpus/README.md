# corpus/

One file per transaction, `*.case`. `cargo test --test corpus -- --nocapture`
runs them all and prints how many are real and how many synthetic.

## Format

```
source:   synthetic | real:<tx hash or URL>     required
note:     free text                              optional
expect:   safe | review | high | undecodable     required
flags:    UNLIMITED_AMOUNT UNTRUSTED_SPENDER ... optional, exact set; empty = none
error:    Truncated | DirtyPadding | ...         optional, only with `undecodable`
trusted:  0x<20-byte address>                    optional, repeatable
calldata: 0x<hex>                                required
```

Unknown keys, duplicate keys and bad values fail the test on purpose.

## Adding a real transaction

1. Copy the calldata from the explorer (the "Input Data" in hex, not the decoded view).
2. Decide the verdict **before** running anything: what should a careful
   person be told about this transaction? Write it as `expect:`.
3. Put the addresses you would trust in `trusted:` (the router the app really uses, your own accounts).
4. Run `cargo test --test corpus`. A mismatch is one of three things, and
   the work is deciding which: a bug in the crate, a wrong expectation, or
   a case the crate does not support yet (then `undecodable` is the honest verdict).

`undecodable` for a perfectly normal swap is not a failure of the corpus; it
is the measurement. Count how many real transactions land there before
choosing the next decoder to write (swap commands, router recipients, ...).

## Synthetic seeds

52 cases: the eight single-call rules, `multicall` and Multicall3 batches, and 22 Universal Router plans (`synthetic-ur-*`: permits, permit batches, sub plans, the allow-revert bit, unassigned commands, bad layouts).

`synthetic-*.case` are generated by `tools/gen_synthetic_corpus.py`, which
encodes the calldata independently of the crate (the Multicall3 cases through
a generic head/tail ABI encoder, not a copy of the crate's layout). They are not evidence about
real traffic. Do not edit them by hand; edit the generator and re-run it.

A case whose note starts with `KNOWN GAP` records something the crate does not
judge yet (for example a swap that pays a stranger, which comes out `review`).
It is there so the gap is visible and so the case flips when the gap closes;
it is not a claim that the verdict is right.
